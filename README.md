# City Route Planner

A Java-based console application that models a city as a weighted graph and helps users find the shortest route between locations using **Dijkstra's Algorithm**. The project also demonstrates **Breadth-First Search (BFS)** and **Depth-First Search (DFS)**, showcasing the practical application of Object-Oriented Programming (OOP) and Data Structures & Algorithms (DSA).

---

## About the Project

City Route Planner represents a city as a weighted graph where:

- Locations are represented as **vertices (nodes)**
- Roads are represented as **weighted edges**
- Edge weights represent the distance between locations

Users can interact with the system through a menu-driven interface to explore the city map, perform graph traversals, and find the shortest path between two locations.

## Features

- Display the city map
- Find the shortest route using Dijkstra's Algorithm
- Display the total shortest distance
- Display the complete shortest path
- Breadth-First Search (BFS) Traversal
- Recursive Depth-First Search (DFS) Traversal

## Algorithms Implemented

### Dijkstra's Algorithm
Finds the shortest path and minimum distance between two locations.

### Breadth-First Search (BFS)
Traverses the graph level by level.

### Depth-First Search (DFS)
Traverses the graph recursively.
